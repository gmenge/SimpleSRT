# SimpleSRT

Receptor de vídeo SRT para Windows, feito com C#, WPF e LibVLC.

## Como executar

Requer o SDK do .NET 8.

```bash
dotnet run --project SimpleSRT.App.csproj
```

## Instalador

`installer.iss` gera o instalador com o Inno Setup, a partir da versão publicada do aplicativo.
